# 👋 Hi, I'm George Boateng-Sarfo, PhD

### 🧬 Computational Biologist | Bioinformatician | Bioinformatics Software Developer

I'm a computational biologist and bioinformatics software developer
with research interests in RNA biology, gene regulation, genomics,
epitranscriptomics, and computational method development.

My work focuses on developing computational tools and reproducible
bioinformatics pipelines to investigate RNA processing, alternative
splicing, alternative polyadenylation, RNA modifications, and their
roles in biological processes and human diseases.

single-cell transcriptomics, long-read sequencing, and computational
models to understand complex mechanisms of post-transcriptional
gene regulation.

## 🛠️ Bioinformatics Software Development

I develop computational tools for investigating RNA processing,
transcript architecture, genomic annotations, and gene regulation.

### 🧬 APAURA
**Alternative Polyadenylation Architecture, Usage, and Regulatory Analysis**

A computational framework for investigating alternative
polyadenylation across multiple sequencing technologies.

Features include:
- Tandem 3′ UTR analysis (TUTR)
- Alternative last exon analysis (ALE)
- Intronic polyadenylation (IPA)
- Mixed APA architecture classification
- Polyadenylation site identification and usage
- Differential APA analysis
- RNA-binding protein motif enrichment
- Bulk and single-cell transcriptomic analysis
- Publication-quality visualizations

### 🧬 PolyAShift
**Alternative Polyadenylation Analysis**

A computational tool for investigating differential
polyadenylation and transcript 3′-end regulation.

### 🧬 Splice2Protein
**Predicting Protein Consequences of Alternative Splicing**

A transcript-aware computational framework for interpreting
alternative splicing events and their potential effects
on protein sequences.

Features include:
- Integration with rMATS results
- Transcript-aware splicing interpretation
- Expression-informed transcript prioritization
- Prediction of protein sequence consequences
- Integration with transcript quantification results

### 🧬 PeakLocus
**Transcript-aware Genomic and RNA Peak Annotation**

A computational framework for annotating genomic and RNA
peak coordinates within transcript structures.

Applications include:
- RNA modification peak annotation
- Transcript-aware genomic feature mapping
- RNA-centric functional annotation
- Integration with transcriptomic datasets

### 🧬 sc3UTR
**Single-cell 3′ UTR and Alternative Polyadenylation Analysis**

A computational framework for investigating alternative
polyadenylation and 3′ UTR usage at single-cell resolution.

Features include:
- Single-cell polyadenylation site quantification
- Cell-type-specific 3′ UTR usage
- Differential APA analysis
- Integration with single-cell transcriptomic workflows
- Support for different single-cell sequencing platforms
